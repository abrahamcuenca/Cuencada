# WP-0.7 Mobile-first design system
Owner: UI/UX · Reviewers: TL · Branch: wp/0.7-design-system · PR: # (not opened; orchestrator to open)

## Scope
Everything here was delivered. Only the paths below were touched; nothing in WP-0.6's `app/`, `router.tsx`, `store.ts` or `shared/api/`. Existing pages and `styles.css` were not changed.

- **Tokens and base:** `apps/web/src/shared/styles/tokens.css` and `base.css`. They cover:
  - semantic colour, contrast-checked
  - a fluid type scale
  - spacing, radii, shadows, z-index, motion and safe areas
  - documented breakpoints at 600, 900 and 1200
  - a reset, focus ring, reduced motion and utilities
- **Primitives:** `apps/web/src/shared/ui/`, all exported from `index.ts`:
  - Button, IconButton, Card, Field
  - TextInput, TextArea, Select
  - Checkbox, Switch
  - Dialog, BottomNav, TopNav, PageShell
  - AvatarCircle, AvatarStack
  - ToastProvider / useToast
  - Spinner, Skeleton, EmptyState, Tabs, Badge
  - Countdown (+ `getCountdown`)
  - Lightbox
  - nav helpers: `isPathActive`, `renderRouterLink`, `renderAnchor`
- **Style guide:** `apps/web/src/shared/ui/StyleGuide.tsx`. It's dev-only and exports `StyleGuide`, `Component` (for react-router `lazy`) and `default`.
- **Tests:** Dialog (incl. unmount-while-open and StrictMode focus restore), Field (+ Checkbox) a11y wiring, Countdown states, BottomNav active state (+ `isPathActive`), Lightbox (keyboard, buttons, swipe, video-drag guard, focus at ends), Toast timing, Button `rel`, AvatarCircle retry and the TopNav brand link. That's 53 UI tests.
- **Docs:**
  - `docs/ux/design-system.md`
  - `docs/ux/wireframes.md`: every screen in the plan, with Spanish microcopy
  - `docs/ux/screenshots/*.webp`
- **PWA icons:** in `apps/web/public/icons/`:
  - `favicon.svg`
  - `icon-192.png`, `icon-512.png`
  - `maskable-192.png`, `maskable-512.png`
  - `apple-touch-icon.png` (180)
  - They're generated by `scripts/generate-icons.sh` with ImageMagick, because `sharp` is not installed in the repo; the script uses `rsvg-convert` if present.
- **Assets:**
  - `apps/web/public/images/Bandera_Mexico.webp` is the legacy flag, re-encoded as real WebP at 240px wide.
  - `apps/web/public/images/logo-96.webp` is a 96px header logo (4 KB vs 640px JPEG).
  - The mislabeled `apps/web/public/images/Bandera_México.png` (WebP bytes, nothing referenced it) was removed.

## Decisions
- **No webfonts.** `ui-rounded` (SF Pro Rounded) leads the display stack for warmth on Apple; everything else uses the system stack. That's 0 KB, which protects LCP.
- **Signature element:** the papel picado scalloped edge (`.cu-papel-picado`), a CSS mask with no images. It's used once per page.
- **New festive accent "bugambilia" `#a61b4a`** for unread counts and "new" markers, so gold stays reserved for the primary CTA.
- **WhatsApp button uses ink text** (`#0b2e1a`, 7.46:1). The legacy white-on-`#25D366` was 1.98:1 and failed AA.
- **Focus ring:** a 3px dark outline plus a 3px gold halo. It is visible on cream, white and the green hero.
- **Dialog and Lightbox use native `<dialog>`** with a JS focus trap and a fallback when `showModal` is missing (jsdom). The Lightbox does not wrap around.
- **Button labels wrap; they never truncate**, so long Spanish labels stay readable at 320px.
- **`TextInput`, `TextArea` and `Select` share `controls.module.css`** instead of three near-identical modules. This is a small deviation from the one-module-per-component convention.
- **TopNav renders below 900px too**, as a brand-only app bar; the links appear at 900px and up. `hideOnMobile` opts out.
- **`vite-env.d.ts` lives at `apps/web/src/vite-env.d.ts`.** It's app-wide, so it moved out of `shared/ui` after review.
- **Flag filename is ASCII** (`Bandera_Mexico.webp`) to avoid percent-encoding issues in URLs and caches.
- **Screenshots** are committed as WebP under `docs/ux/screenshots/` (about 600 KB total) so reviewers can see them without running the app.
